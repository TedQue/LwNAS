# LwNAS - Light-weight Network Attached Storage
## 简介
---
LwNAS 是一个 Rust 语言开发,基于 Axum 框架实现的 HTTP 服务器.  
预设的使用场景是家庭局域网内部,方便家庭成员使用手机,平板,电脑自带的浏览器查看,上传文件,图片,视频.  
LwNAS 集成了专门针对此场景应用的前端页面和后端服务.

## 实现机制
---
### 1. 目录映射
LwNAS 服务器内部实现了 3 种路由:
- / - 显示主页,列出配置文件中指定的目录表
- /shutdown - 远程关闭入口,可在配置文件中禁用此功能
- 其他 - 所有其他请求根据 URL path 部分与目录映射表的记录依次比较,映射为文件系统中的文件或文件夹,在映射为文件路径前会先规范化 path,去除其中的 ./ ../ 等部分,限定用户只能访问目录映射表中的文件路径,防止逃离造成安全风险

### 2. 上传文件重名冲突处理策略
LwNAS 检测到上传文件名冲突时,有以下几种处理策略可选:
- overwrite - 覆盖
- skip - 忽略
- appenduuid - 文件名追加 UUID v4 之后再次尝试写入
- appendtimestamp - 文件名追加时间戳后再次尝试写入

### 3. 缩略图生成机制
多个请求同时到达时,有可能并发生成同一个缩略图导致文件写入竞争, LwNAS 设计了互斥锁,等待队列以及广播通信机制,可以安全生成缩略图.

### 4. 自定义模板外观
LwNAS 使用 Tera 模板实现前端页面渲染,用户可编辑 templates 目录下的模板文件实现自定义外观.

## 部署
---
一个典型的 LwNAS 工作目录布局如下:  
```
<dir> logs                # 日志目录 (手动创建)  
<dir> thumbs              # 缩略图目录 (手动创建)  
<dir> tmp                 # 上传文件临时目录 (手动创建)  
<dir> root                # HTTP 根目录 (手动创建,需要共享的文件也存入此目录)  
<dir> templates           # 外观渲染模板 (从源码包复制)  
lwnas.exe                 # LwNAS 可执行文件 (从源码编译输出目录复制)  
default.toml              # 配置文件 (从源码包复制,并按需求修改)  
```

工作目录准备就绪后运行 `lwnas.exe default.toml` 启动 LwNAS 服务.
